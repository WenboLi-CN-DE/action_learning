# Roadmap: AI工坊平台

## Overview

AI 工坊平台从信息汇总 MVP 演进为需求—能力协同治理平台，并在 v2.1 补齐个人待办、SLA、数据质量、AI 评测和管理指标。2026-07-29 决定以 v2.1 为最终功能范围，不再建设 v2.2/v2.3。

## Phase Details

### Phase 5: AI 候选匹配闭环

**Goal:** 在保留人工决策权的前提下，用 LLM 对需求和能力池进行关联性分析。

**Delivered:**
- 标签与文本重合度预筛选候选能力
- LLM 综合评分、覆盖状态、匹配理由、能力缺口和维度评分
- 需求详情页展示 Top N 推荐并支持人工确认
- 正式关联保存 AI 来源、分数、理由、缺口和模型信息
- 模型输出边界校验、异常处理与后端测试

### Phase 6: v2.1 试运行闭环

**Goal:** 让现有业务闭环能够明确回答“现在轮到谁、是否逾期、数据质量如何、AI 推荐是否有效”。

**Delivered:** 角色个人待办；48/72 小时 SLA；即将到期和逾期提示；需求/能力数据质量评分；低质量清单；人工审核结果驱动的 AI 候选采纳率、样例和缺口统计；审核人覆盖、候选覆盖、审核周期和匹配周期管理看板。

### Phase 7: 企业化与系统集成（取消）

2026-07-29 决定不建设 v2.2/v2.3。SSO/RBAC、PostgreSQL/Alembic、实时通知、CRM/Jira/Confluence 集成、复杂 BI 和移动端全部移出最终范围。

允许的后续工作仅包括缺陷修复、现有部署维护、真实试运行数据补充，以及必要的弃用 API 兼容维护。

### Phase 8: 角色入口与角色视图

**Goal:** 平台从"数据库管理界面"转向"角色工作台"，用户按身份进入各自视角。

**Requirements**: ROLE-01~07, VIEW-01~04

**Success Criteria** (what must be TRUE):
  1. 进入平台先选择身份（销售/咨询、研发、管理员），无需密码，身份持久化在本地并可切换
  2. 销售进入需求池视图：我的需求卡片流（匹配度、状态标签）+ 常驻 AI 需求助手；能力池只读
  3. 研发进入能力池视图：能力维护 + 待评估需求收件箱；需求池只读但可确认匹配
  4. 管理员可访问全部视图和汇总统计面板
  5. 界面操作（新建/编辑/确认按钮）按角色显隐

**Delivered:** Zustand + localStorage 身份状态、无密码角色入口与身份切换；销售需求卡片流、研发能力维护/需求收件箱、管理员总览/审核队列；各角色操作按能力显隐，非法持久化角色会回到角色入口。

### Phase 9: 审核工作流

**Goal:** 需求受理和匹配确认有明确的责任人和留痕，审核机制在平台上可见。

**Requirements**: REVIEW-01~07, DATA-01~03, GOV-01~07

**Success Criteria** (what must be TRUE):
  1. 需求状态机生效：草稿 → 待审核 → 已受理 → 匹配中 → 已匹配 / 已搁置
  2. 销售提交的需求进入"待审核"，管理员在审核队列中受理或退回
  3. 手动/AI 匹配创建后先由研发技术确认，再由管理员终审后生效
  4. 需求/匹配详情页可见审核历史（谁、何时、结论）

**Delivered:** Requirement 状态转换与审核 API、旧版状态兼容入口、审核责任人指派与受理/退回；详情展示提交人、责任人、实际审核人和意见；Match 研发技术确认 + 管理员终审；禁止创建人自审、技术确认人与终审人分离、驳回意见必填；审核事件留痕与详情展示；新需求描述质量校验和历史数据缺失提示。

### Phase 10: Chatbot 与知识库管理

**Goal:** 降低使用门槛——不会用平台的人可以直接问；知识库从搜索页升级为可运营的知识底座。

**Requirements**: AI-01~03, CHAT-01~03, KB-01~05

**Success Criteria** (what must be TRUE):
  1. 平台任意页面可唤起对话助手，基于 RAG 回答问题并附引用来源
  2. 对话助手可从自然语言生成需求草稿并引导提交（复用 AI 结构化能力）
  3. 知识库管理界面可查看已导入文档（来源、时间），支持删除与重建索引
  4. Chatbot 回答基于知识库内容，与 RAG 底座打通

**Delivered:** 多轮 RAG + Qwen Chatbot API、引用来源与空知识库降级提示；全局悬浮 AI 助手和需求草稿生成；知识文档列表、删除、重建索引；持久化文档元数据与跨进程唯一文档/分块 ID。
